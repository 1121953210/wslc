## 一、引言

「腕上灵宠 BioPet」（以下简称"本应用"）是一款运行在华为智能手表上的健康陪伴应用。它将您手表记录的**心率、压力、步数**等健康数据，实时映射为一只会呼吸、会随您的身体状态改变表情与姿态的虚拟宠物，帮助您以更直观、更有情感的方式了解自己的健康趋势。

我们深知健康数据属于您的**敏感个人信息**。本政策用于说明：我们访问哪些数据、用来做什么、如何处理与存储，以及您享有哪些控制权。**请您在使用本应用前仔细阅读并充分理解本政策**，重点内容已用加粗标示。

**特别提示：本应用不构成医疗软件。**

## 二、我们访问的数据及用途

本应用通过华为运动健康服务（Health Service Kit）申请以下数据权限，各项数据的用途与申请材料清单中申报的场景**完全一致**，不用于任何其他目的：

| # | 数据类型 | 使用用途 | 是否上传 |
|---|---|---|---|
| 1 | **心率数据** | 读取实时心率，用于展示心率统计信息，帮助您了解心率情况；同时驱动虚拟宠物的心跳节奏与动画频率 | **否，仅本机处理** |
| 2 | **压力数据** | 读取实时压力数据，根据不同压力水平展示对应的宠物状态（如平静、紧张、愤怒） | **否，仅本机处理** |
| 3 | **步数数据** | 读取实时步数，根据不同步数区间展示不同的宠物状态（如休眠、舒展、飞驰、趴窝） | **否，仅本机处理** |
| 4 | **睡眠信息** | 读取睡眠数据，用于后续版本的功能优化与个性化体验改进；**当前版本不会将睡眠数据用于任何展示或分析** | **否，仅本机处理** |

除上述由华为运动健康服务提供的授权数据外，本应用还有一项由您**主动手动记录**的数据：

- **喝水打卡记录**：由您点击"喝水打卡"按钮自行记录的每日饮水杯数。该数据完全由您手动产生，**不来自任何传感器或设备推测**，仅用于活力值计算与喝水打卡提醒，仅存储在本机。

## 三、数据处理方式：仅在本机，不上传服务器

这是我们最希望您了解的一点：

1. **本应用不设服务器，不上传任何数据。** 您的心率、压力、步数、睡眠、喝水打卡记录**全部只在手表本机**被读取和计算，用于驱动宠物的实时表现。
2. **我们不与任何第三方共享、出售或提供您的数据**，包括广告商、数据服务商、分析机构。
3. 宠物状态、活力值、成长进度等全部由**本机本地计算**得出，数据不会离开您的设备。

## 四、数据存储与保留

1. **存储位置**：全部数据仅存储在手表本机的应用数据目录（系统沙箱内）。
2. **保留期限**：在您使用本应用期间持续保留，用于成长进度与打卡记录的连续性。
3. **删除方式**：
   - 在系统设置中清除本应用数据或卸载本应用，所有本地记录（含成长进度、喝水打卡）将被**彻底删除且不可恢复**；
   - 您也可以在华为"运动健康"App 中管理或删除由系统记录的健康数据。
4. **授权数据来源说明**：心率、压力、步数、睡眠数据的原始记录由华为运动健康服务体系生成与保管；本应用仅在获得您授权后按上述用途读取使用，不复制、不另存原始记录之外的副本。

## 五、您的权利与控制权

您对上述数据拥有完全的控制权：

1. **授权前置**：本应用首次使用相关功能时会通过系统弹窗向您申请授权，**您可以拒绝**；拒绝后对应功能（如心率驱动的宠物状态）将以默认表现运行，不影响其他功能使用。
2. **随时撤回**：您可以在 **手表/手机的 设置 → 应用 → 权限管理**，或 **运动健康 App → 我的 → 数据授权** 中随时取消对本应用的授权。撤回后，本应用立即停止读取对应数据。
3. **按类型授权**：您可以对每一类数据（心率/压力/步数/睡眠）**单独选择授权或不授权**，本应用不会因您拒绝某一项而限制其他功能。
4. **删除数据**：见第四条第 3 款。

## 六、非医疗用途声明

**本应用数据基于智能算法生成，仅供健康趋势参考，不构成医疗诊断。**

- 本应用展示的宠物状态、活力值、成长进度均为**娱乐化、具象化的可视表达**，不是医学指标；
- 本应用不能用于诊断、治疗、治愈或预防任何疾病；
- 若您感到身体不适，或心率、压力等指标持续异常，请及时就医并遵医嘱，不要以本应用展示内容作为医疗决策依据。

## 七、未成年人保护

本应用主要面向成年用户。若您为未满 14 周岁的未成年人，请在监护人陪同下阅读本政策，并在征得监护人同意后使用本应用及其健康数据授权。
